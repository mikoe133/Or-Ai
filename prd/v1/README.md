日期：2026-10-16。状态：T01–T05、T06-L、T07 本地运营接口已验收；T06-C 真实云端认证/收信和对象存储待 T09 验收。采用本地开发优先、云端接入后置；下一开发任务为 T08，本轮未开始。T12–T14 内容后台与 T15–T17 多形态体验仍为后续规划；具体证据见 PROGRESS.md。

本版按用户最新要求调整：先搭建聚合主平台，商品暂用大致内容占位；手机和网页 Figma 设计已完成，页面覆盖接入前核对。占位内容用于验证平台能力，正式商品题库、营销素材和真实销售不作为平台开发的前置条件。

## 云端接入前可以执行到哪一步

**可以完成 T01–T08 的本地功能范围，再进行 T10 的本地视觉接入。** 商品目录、兑换权益、动态答题/报告/统计、运营接口和消费者页面使用真实本地数据库与 API；账户权限已通过隔离测试。T06-C 真实邮件和云端账户不再阻塞这些开发。

当前未配置 Auth 时，账户页显示尚未配置，匿名兑换独立可用。需要本地手动验证账户/后台登录时，可另行配置本地 Supabase Auth 与邮件收件工具；目前尚未启动。不开放测试身份作为生产登录入口。

**T10 视觉实现不依赖公网。** 手机/桌面稿实现为同一套响应式前端，正式设计可按页面接入。只有首页有稿不代表答题、报告、账户和运营后台全部定稿，缺失页面单独保留待设计项。

**T09 后置统一验收云数据库、Supabase Auth＋Resend、对象存储、公网托管及完整业务 E2E。** 主平台整体完成仍要求 T09、T10 都通过；T11 的正式商品、销售权限和交付政策另行验收。详细顺序见 LOCAL-FIRST.md。
