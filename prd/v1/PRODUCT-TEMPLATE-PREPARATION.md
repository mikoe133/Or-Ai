## 能力与当前约束

商品正常体验须有实际Three.js场景，帮助用户理解自己或关系；视觉、空间、镜头、动画和操作由具体商品规划决定。运营人员最终应能选择符合该商品的真实模板，固定同一内容/评估/报告/媒体来源，历史权益仍读取旧版本。

当前注册表只有一组WebGL商品组合：`reflection-garden@1`＋`garden-notes@1`，使用内置几何体，2–4个明确单选，服务端`dimensions_v1`评分。`garden-scene.ts`固定花园几何/色彩/透视镜头，`garden-renderer.ts`接受选择与失败回调，当前不能仅靠任意theme key或规划文案切换正交地图、配色或相机行为。旧DOM/2.5D小屋只作历史兼容，不满足新的正常商品Three.js规则。

因此本准备采用两份有区别的**合成技术草案**，不假称运行模板已按草案制作，也不把可保存的规划当作交付。

| 维度 | 合成A：花园观察参考 | 合成B：关系坐标提案 |
| --- | --- | --- |

| 视觉/空间 | 3D低多边形花园；已有模板兼容时才考虑复用 | Three.js正交2.5D分层坐标台，保持真实深度/选择语义 |

## 06 性能目标（待实际测量）

| 项目 | A参考上限 | B提案上限 | 测量口径 |
| --- | --- | --- | --- |
| renderer gzip | 240KiB | 220KiB | 独立惰性chunk及实际依赖，不用源码字节冒充gzip |
| 资源总字节 | 1MiB | 512KiB | 固定清单的实际文件；本准备没有导入资源 |
| 首帧 | 3000ms | 3000ms | 固定开发机/浏览器/CPU与网络条件，冷缓存重复样本；不能当真机成绩 |
| DPR / canvas像素 | 1.5 / 1500000 | 1.25 / 1000000 | 实际绘制缓冲，不只读CSS尺寸 |
| 三角形 / draw calls | 14000 / 48 | 8000 / 32 | render.info的实际帧数据，声明上限不是实测成绩 |
| 互动帧率 | ≥30fps | ≥30fps | 只在需要绘制的选择/镜头阶段采样；按需渲染的空闲0帧不是性能失败 |

目标设备声明含桌面、iOS Safari、Android Chrome、微信和平台webview；本地先用实际桌面浏览器及1440/768/390视口验证，真机/三网/内置浏览器最终由10持有。固定测试设备、浏览器版本、冷/热缓存、重复次数、网络/CPU条件及资源版本后才记结果；未测字段保持未验。

## 06 功能、恢复与边界矩阵（全部待执行）

| 场景 | 必须保持的业务事实 | 核对证据 |
| --- | --- | --- |
| 兑换→选择→明确确认→报告 | 服务器评分、一次消费、固定版本 | API状态、回执与CUA路径 |
| 保存冲突/重试/刷新 | 确认过的答案不丢，未确认选择不误提交，同requestId恢复 | 修订/请求ID及前后输入 |
| 点击/拖动/键盘 | 镜头、动画和拖动不改变答案或分数，焦点可见 | 同输入服务端结果比较 |
| 减少动态/窄屏长文 | 关键题意、选项、确认和报告始终可读可用 | 视口/系统偏好与截图 |
| 懒加载/资源失败 | 同题回退，不换题、不假称已导入/已完成 | 失败注入、固定清单和恢复 |
| 无WebGL/context丢失与恢复 | 正常3D与故障文字回退语义一致，恢复不重复消费 | context事件、答案/权益状态 |
| 断网/未知写入结果 | 重试复用身份，不复制答卷/报告/文件 | 请求/版本/消费计数 |
| hidden/卸载/重复进出 | 停止RAF/监听器，释放自建几何/材质/纹理/上下文 | render.info、销毁记录和多轮稳定性 |
| 退款/撤权/第二身份 | 原授权失效，不从缓存泄漏他人报告 | 权益状态与拒绝响应 |
| 历史商品/报告恢复 | 原DOM/其他版本仍按原固定引用可读，不批量改分或迁移进度 | 原版本/摘要、统计隔离与保全 |
