## 操作流程

1. 保存固定修订的共同创作设定。到四类库审核并启用需要的方法，再在商品「skill 组合」中分别选择题目设计、报告写作、封面设计、视频制作、引流文案五个用途。题目与报告可来自同一 skill，也可采用不同 skill 或保留不同版本。
2. 候选按 **ACTIVE 版本自身的 manifest** 筛选领域、用途和商品形式，支持检索/分页；最新草稿的元数据不会代替启用版。找不到兼容方法时先维护对应库。相同风格标签只帮助查找，不能代替用途/形式校验与人工成套审核。
3. 填写组合说明后保存。组合随当前创作设定追加 r1/r2…，不改写设定或覆盖旧组合。五个用途必须齐备，保存使用 expectedRevision/requestId；冲突保留本地选择，放弃修改后可「读取最新组合」。启用新版后可「刷新可绑定版本」。
4. 新组合一般只能选择合规启用版。上一组合已绑定且后来归档的合规版本，可在相同设定、用途和实际规划校验通过后保留；归档版不出现在新绑定的默认候选中。其他设定不能借此首次绑定归档版本。历史组合继续可读和追溯；缺少当前政策或实际规划输入时须追加新组合后制作。
5. 在题库/报告登记和宣传稿保存时明确选择组合。素材同时固定内容修订、具体输入、版本及制作来源；题库/兼容报告组合分别保留题目设计和报告写作两个版本。人工/历史来源允许明确未关联 skill；不可只填一个任意 skillVersionId 绕过组合。
6. 制作来源是操作者申报：manual/external_ai/mcp 与批次/备注。后台没有执行状态，不因保存来源就显示模型、skill 或 MCP 已运行成功。历史记录一次登记后不可覆盖；更正需产生新内容修订，已审核题库可派生新商品版本。
7. 在「成套采用」选择同一固定组合，再选择已审核题库、就绪封面/成片/文案，核对情绪与理解目标、意象、语言和传播承诺。所有根产物必须申报同一组合；缺少组合、组合不一致、文件损坏或输入不一致会阻止采用。未关联 skill 的原历史流程继续明确导出旧包。
8. 旧组合、制作记录和采用包不会随 skill 升级漂移。历史区可查看五个用途的版本、固定正文和参考摘要，并跳转到归档原版；未采用的新版本需要重新制作与人工审核。

## 固定内容与兼容性

`CreativeSkillSet` 按 creativeProfileRevisionId 追加序号，`CreativeSkillBinding` 对五个用途分别保留 skillId/skillVersionId 及正文/附件快照。快照包含固定 manifest、版本号、摘要和参考文件元数据；排除当前 status/revision/updatedAt、上传会话、actor/owner 和存储路径。当前版本归档会改变生命周期字段，但不会改变固定制作依据。

`ProductionRecord.skillSetId` 指向组合，`skillVersionId` 是本领域主版本（assessment 为 assessment_design），`skillVersions` 保存该输出使用的专业用途快照（assessment 两项，其余一项）。输出修订可定位商品版本，记录同时绑定共同设定及固定输入清单。审核/就绪/发布等仅改变状态的修订会复制全部来源字段与固定输入。

原采用包 **schemaVersion=1** 保持原严格结构和摘要含义；新绑定包使用 **schemaVersion=2**，增加完整 skillSet，根制作记录包含具体 skillVersions。读取旧包不会补默认新字段或重新生成摘要。新包不覆盖旧包，也不代表商品已发布。导出不含消费者作答/报告、身份凭据、操作者 ID 或服务端路径；正文/附件均不会在后台执行。

第十三份向前迁移 `20261020030000_creative_skill_bindings` 增加两个模型（共 43 模型/13 迁移）和来源字段/外键。数据库检查五用途齐备、范围/商品/设定归属、领域/用途/形式、绑定快照与实际版本、来源所声明的组合；组合/绑定/制作记录均只追加。未编辑任何已应用迁移；回退应用时保留历史表与文件，修复数据库使用向前迁移。

## 授权读取与后续 MCP 复用

均为 `/api/admin` 下的真实管理员 API，沿用 scope、Cookie、私密响应，写入使用 Origin/CSRF 和幂等审计。T14-LA 已有机器凭据/上传协议，领域读取/草稿工具留 T14-LB，不能把浏览器 Cookie 当成机器凭据。

| 接口 | 用途 |
| --- | --- |
| GET /skills/:domain/candidates | 必填 purpose/form，可选 q/page/pageSize；兼容启用版本分页 |
| GET /creative-profiles/:id/skill-sets | 固定组合历史分页 |
| POST /creative-profiles/:id/skill-sets | 五个 {purpose,skillVersionId}、note、expectedRevision、requestId |
| GET /creative-skill-sets/:id | 当前范围下的完整固定组合 |
| GET /creative-skill-sets/:id/domains/:domain?purpose=… | 仅该领域/可选专业用途的固定指令与参考；拒绝错领域用途 |
| GET /creative-skill-sets/:id/domains/:domain/:purpose/references/:fileId/content | 校验文件确实属于此固定用途，再授权下载，支持单段 Range |
| POST /content-contexts/resolve | 可选 skillSetId，必须与设定匹配；仅返回请求领域的方法和显式选择的内容节选 |

上下文不会隐含读取其他 skill 库；宣传领域仍须明确 questionId，题目节选不含分值、阈值、私人报告模板或消费者数据。引用同商品已授权文案/封面等内容时只投影明确选择的位置。绑定、上下文、制作和采用会按用途重新检查参考文件字节；损坏文件阻止新操作，已保存采用包仍可读取。
