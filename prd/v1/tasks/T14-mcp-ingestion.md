- [ ] T14.3 用授权上下文接入共用的内容/skill 业务服务，网页 Cookie 路由保留原校验；为机器身份提供明确的受控 API 适配，不通过关闭 CSRF 或新增万能管理员头实现。
- [ ] T14.4 实现四域查询及 context_bundle_get/references_validate；按商品/任务/授权提供同一 creativeProfileRevisionId、情绪/理解目标、参与视角、形式/风格/报告方案、skill 与最小输入清单。视频权限不隐含完整计分、个人报告或跨库写权限。
