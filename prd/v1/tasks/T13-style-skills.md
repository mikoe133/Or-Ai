# T13：四类 skill 库、版本与内容绑定

状态：2026-10-16 新增规划，待执行。依赖：T12 的内容/文件修订与工作台，沿用 T07 的鉴权和审计。对应扩展需求：FR-15。业务约定见 [CONTENT-BACKOFFICE.md](../CONTENT-BACKOFFICE.md)。首期交付 skill 保存、读取和外部制作来源管理；后台执行生成任务另行排期。

## 执行批次

位于 [ROADMAP.md](../ROADMAP.md) 顺序 4，T12 全部通过后执行，不与体验制作 domain 同时扩张。

- T13-A：`.1–.4`，固定元数据与包格式、受控参考附件用途、四库维护、版本生命周期与差异/导出。Markdown/文档附件不伪装成图片/视频，不自动安装或执行内容。
- T13-B：`.5–.8`，商品设定下的专业用途绑定、输入/产物与 skill 来源、授权查询和四库演示。assessment 同时覆盖题目设计和报告写作；体验/报告 renderer 的 experience 扩展留给 T15。

T13-A 通过只代表库可维护；T13-B 的错绑拒绝、旧/归档版本追溯、来源与成套审核通过后才完成 T13，进入 T14-L。

## 子任务

- [ ] T13.1 固定 skill/版本与商品用途契约；必填四领域和专业用途，保存输入输出、支持形式/风格、参考文件、示例、摘要/状态。各域接收相同商品创作设定，assessment 区分题目/规则设计与报告写作；experience 呈现扩展由 T15 接入。
- [ ] T13.2 建立四类独立 skill 入口 `/admin/skills/:domain`，各自检索、详情、参考资料和风格筛选；同名风格不自动混用，不强制不同领域共用一份指令，同一领域 skill 可复用到多个商品。
- [ ] T13.3 提供 Markdown/结构化清单导入与编辑，参考资料走相同文件服务；校验必要元数据、内部相对引用、文件完整性、数量和大小。技能包中的指令/脚本作为内容保存，不在后台执行或安装。
- [ ] T13.4 实现 DRAFT/REVIEWED/ACTIVE/ARCHIVED 流程、差异比较、复制新版本与导出；已启用版本不可覆盖，归档保留历史读取和既有引用，不再作为新绑定的默认选择。
- [ ] T13.5 按创作设定组成明确的 skill 版本组合，题目、报告写作、封面、视频、文案分别绑定且领域/用途/形式兼容；报告呈现按 T15 单独绑定。各库接收情绪/理解目标、共同意象和必要输入引用，制作方式按媒介适配。
- [ ] T13.6 将外部制作记录与 brief 修订、固定输入引用、商品版本、skill 版本及产物修订关联；人工比较/采用本领域不同风格输出，不把未执行记录显示为后台生成成功，skill 升级不覆盖历史制作依据。
- [ ] T13.7 提供按 domain 授权读取/下载的 API 和分页契约，供各领域 MCP 映射；跨领域读取仅限显式获授权的参考输入，未发布 skill 不从公开目录或消费者接口泄露。
- [ ] T13.8 四库各有演示 skill，其中一库两个版本，assessment 覆盖报告写作；验证同一商品设定下的配套产物、输入引用/来源、形式不兼容与跨域错绑拒绝、旧版/归档读取、冲突/脱敏。相同标签不能代替成套内容审核。

## 交付与验收

题库报告、封面、视频、文案各自可维护的 skill 库，及明确版本的内容绑定、输入/输出规范、参考资料和来源追溯。经营者能找到每个产物使用的本领域 skill 与跨库输入，升级后仍能定位旧版本指令和资料。

初始风格使用可替换演示内容，不要求用户先提供正式 skill；首期不承诺兼容所有客户端技能包格式。消费者答题仍调用原固定评分/模板服务，skill 库不改变运行时评分或私人报告归属。
