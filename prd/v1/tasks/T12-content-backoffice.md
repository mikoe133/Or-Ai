- [ ] T12.2 建立四类内容入口与创作设定编辑，按商品/设定修订/平台/风格/状态查询，显示齐备及兼容情况；单人/双方参与能力分开标识。提供题目/过程、报告、封面/视频/文案与分享卡的成套预览。
- [ ] T12.3 编辑/导入题目、规则、现有报告解释/建议和公开样例，调用原版本服务；另以独立且版本化的报告方案草稿 schema 保存/校验章节、叙事与目标呈现要求，不修改旧严格运行配置。新运行投影、renderer 和发布兼容验证由 T15 实现，未支持形式不可进入采用。T12 用既有兼容报告闭环验收，不等待新 renderer；已发布内容派生新版本，公众不读私有模板，不以 HTML 塞旧字段绕过。
- [ ] T12.4 基于 T07 上传能力完善封面/视频预览和授权下载；保存实际 MIME、大小、摘要、尺寸/时长，处理上传中断、超限、校验失败和重启后的文件读取。沿用 T07 限制，按实际样本调整配置并固定测试。
- [ ] T12.5 实现结构化文案块和视频分镜：稳定 blockId/sceneId、钩子/正文/字幕/口播/CTA、分镜时序、题目/文案/封面引用及实际使用文本；视频缩写题干记录为改写，不修改原题。平台版本与 A/B 变体独立。

## 交付与验收

受保护的四类内容工作台、共享选题说明、内容引用与影响分析、素材/文件修订、题库报告编辑器、固定采用组合及来源记录。数据库保存结构与文件引用，受控持久目录保存本地文件；缺失/失败项不能算素材齐备。授权用户能定位视频中的具体题目和文案版本，普通用户无后台访问权限。

T12.10 的真实测试视频指实际可读取播放的演示文件，不要求商业成片。云端 R2、真实管理员登录与公网大文件限额另由 T09 验证；后台正式视觉单独记录，不以消费者 Figma 稿代替。

本任务不运行模型、skill 或视频渲染，不发布到社交平台。T13 补充 skill 库，T14 提供共用这些服务的 MCP 入口。
