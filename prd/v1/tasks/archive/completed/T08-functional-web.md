## 交付与验收

可点击操作的功能联调前端与必要 E2E 验证。页面数据来自真实后端，刷新/返回能恢复条件/进度；统计不可用仍能继续。普通用户不能操作后台，退出/切换身份不展示上个用户的私密缓存。

**这是无需云端配置即可推进的本地功能范围。** T08 全部本地必需项验收后，按原执行范围停止；T06-C 和云端 E2E 仍保持待验收。未配置 Auth 时如实提示，不以可访问页面壳代替账户/后台功能验证。正式双端 Figma 设计经 T10 接入，T10 本地部分可以安排在 T09 前。

后续内容工作台、完整题库报告编辑、素材修订/导出、风格 skill 库和 MCP 连接管理按 [CONTENT-BACKOFFICE.md](../../../CONTENT-BACKOFFICE.md) 及 T12–T14 实现。它们不计入 T08 必需验收，也不要求本步完成后台正式视觉。
