## 交付与验收

公网测试地址、Cloudflare 配置、存储/认证/数据库实测与备份/回滚记录。真实网络能完成浏览、兑换、答题、报告及邮件回调；冷启动/重启不丢业务状态，私密响应不缓存。

本步无需最终 UI，但不是仅有部署配置文件即可算完成。Cloudflare Containers 需 Workers Paid（已核验 $5/月起，另计用量）；预算/账户未就绪时保留待执行，不未经授权开通收费套餐。国内链路不达标先调整托管/区域，不冒充“全球 CDN 即国内稳定”。

T12–T14 是独立后台扩展；尚未启用时不增加 T09 原平台验收前置。后续远程 MCP 需 [T14-C](T14-mcp-ingestion.md#t14-c-远程接入-待云条件就绪) 的 Streamable HTTP、授权/发现及真实客户端验收，不能仅凭本地 stdio 已通过宣称远程可用。

T15–T17 的多形态商品也是独立扩展。已启用时按固定资源清单验证模型/纹理/音频的存储、类型/大小/读取权限与历史资源保留，并实测手机和平台内置浏览器的加载、降级和恢复；未启用不阻塞原云链路验收。
