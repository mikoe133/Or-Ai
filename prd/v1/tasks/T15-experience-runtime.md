# T15：体验模板、发布清单与运行协议

状态：2026-10-16 新增后续规划，待执行。基础运行依赖 T05、T08；后台完整管理复用 T12，experience skill/MCP 接入在 T13/T14 可用后补齐，不阻塞基础运行验证。对应扩展需求：FR-17。统一约定见 [EXPERIENCE-PLATFORM.md](../EXPERIENCE-PLATFORM.md)。

## 执行批次

推荐位于 [ROADMAP.md](../ROADMAP.md) 顺序 6，在四领域本地制作链稳定后执行；这是排期选择，基础运行的硬依赖仍仅为 T05/T08。

- T15-A 基础运行：`.1–.6` 和 `.8` 的基线回归。先固定体验/报告 schema 与兼容注册表、向前迁移，再接 DOM 单选模板、确认/恢复、资源权限和同内容回退；历史答卷/报告保持可用。
- T15-B 成套 authoring：`.7` 和 `.8` 的后台/机器联调。在 T12 配置体验和报告形式，扩展 T13/T14-L 的 experience 专业用途、资源与上下文权限；新报告内容/呈现双向校验，不直接向旧配置加未知字段。

T15-A 通过可启动 T16-A；两批均通过才标记 T15 整体完成。资源/renderer 未支持时不允许以“上传成功”冒充新形式可发布，不新增评估玩法。

## 子任务

- [ ] T15.1 在商品创作设定下固定内容/评估/交互/主题契约；体验发布清单关联设定、内容、体验/报告模板、主题/资源版本，承接情绪/理解目标。报告结构化结果与叙事/呈现分开，不向严格 v1 配置任意加字段。
- [ ] T15.2 通过向前迁移/契约扩展保存体验发布配置、题目/对象映射、检查点和答卷的固定发布引用；保留旧商品默认 DOM 模板，既有内容/报告不可变约束不改写。
- [ ] T15.3 建立体验宿主与报告呈现注册表，按兼容 schema/renderer 懒加载，统一题目、确认/保存、反馈及完成；体验到报告保持商品意象和语言，旧版图文报告有明确兼容模板。
- [ ] T15.4 注册现有 DOM 单选模板；定义场景选择到 questionId/optionId 的适配，确认后才保存；前端不接收计分权重、不自报分数或完成。
- [ ] T15.5 固定中断/恢复与兼容回退：服务端已确认答案为准，版本和检查点锁定，场景加载失败可用同内容简化呈现，不新建权益、不重复扣次。
- [ ] T15.6 为模型/纹理/音频/插画等资源固定独立用途、清单、摘要和读取权限；先支持审核并注册的模板，上传资源/配置不成为任意代码执行入口。
- [ ] T15.7 在 T12 配置/预览体验与报告形式、主题、资源和创作设定引用；T13/T14 后扩展 experience 的场景/报告呈现 skill 用途、MCP 草稿/校验与权限。基础运行、成套后台与机器接入分别记录，未启用不标完成。
- [ ] T15.8 验证旧单选商品、同答案相同评分、公开清单无私有规则、过期/撤权、并发保存、版本固定、刷新恢复及回退不重复消费；现有统计按商品版本隔离，不将新交互数据静默混入旧版本。

## 交付与验收

体验宿主、模板注册、版本化清单、标准选择协议和兼容 DOM 基线。T15 基础运行可用后 T16 可以开始；T15 整体完成还需 T15.7 的后台/机器接入在相应依赖就绪后验收，不把可运行样例当作已完成完整 authoring。

本任务不增加排序/动作/真正分支评估；这些由 T17 实现。现有 T05 验收仍只代表 dimensions_v1 的已有能力。
