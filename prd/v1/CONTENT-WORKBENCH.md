# T12-B 四类内容工作台交接

2026-10-19，本地实现。入口为 `/admin/content` 与 `/admin/content/:productId`，沿用真实管理员权限、既有后台导航和内容区滚动。数据契约和历史约束以 [T12-A 底座](CONTENT-FOUNDATION.md) 为准。

## 已实现的编辑流程

1. 搜索商品，选择任意题库版本（包含草稿）和共同创作设定修订。
2. 编辑受众、情境、情绪/理解目标、参与视角、形式、世界观、语言/视觉/声音及渠道；每次保存追加一份设定修订。报告叙事方案含稳定章节 ID，独立保存和结构校验，明确标为创作草稿。
3. 编辑题干、稳定题目 ID、维度、选项/分值、解释与建议；完整规则、信息不足模板和保留期可通过 JSON 文件导入。严格 schema 校验后调用原版本服务。已发布题库只能派生新草稿，不能原地覆盖。
4. 独立编辑公开报告样例，与私有报告模板分开；当前分享卡文字试读使用公开样例，不表示新卡片 renderer 已上线。
5. 编辑封面标题/说明、稳定文案块及用途、视频/脚本分镜和时间。新增项使用稳定 key，不随排序或保存重新生成。纯脚本属于 video 领域。
6. 素材按平台和 A/B 变体独立保存；可按当前商品版本、设定修订、平台、状态和视觉风格关键词查询。四类齐备提示区分文本、草稿和正式文件；兼容提示区分当前单人网页能力与规划中的双方/3D/小游戏形式。
7. 分别登记本地原件、上传轻量预览、上传正式文件；展示三种状态，文件可以播放/查看和授权下载。只有本地登记/预览时允许保存草稿，审核/就绪仍需要正式媒体文件。
8. 制作来源、批次和备注随素材修订保存。题库修订可单独登记一次来源；来源更正需新增修订。固定输入 JSON 可保存修订/摘要/具体位置/实际使用文本，详情显示来源记录和输入快照。skillVersionId 当前明确为空，来源申报不表示后台执行了模型或 MCP。
9. 整套试读显示所选题库、兼容报告、设定中的叙事方案、当前设定下各平台的封面/视频/文案和公开样例。

页签切换保留未保存表单；修改未保存时阻止切换题库/设定/稿件和点击链接离开，刷新/关闭触发浏览器提示。保存与放弃有明确按钮。题库、设定和页签选择通过 URL 保留，刷新后可回到所选工作上下文；表单正文不写入浏览器持久存储。旧修订冲突保留编辑内容并提供“读取最新稿”。

## 文件探测与迁移

新增向前迁移 `20261019110000_verified_media_metadata`，只为 AssetFile 添加 `width / height / durationMs` 与约束，扩展已校验文件不可变保护。没有改已应用迁移、重置数据库或重播 seed；原六类业务表行数及内容摘要不变。

沿用 T07 的受控本地目录、独占写入、防路径/符号链接、流式大小/MIME/SHA-256 检查及授权 Range 下载。完成阶段重新校验文件，并通过固定版本 image-size / Mediabunny 从文件读取尺寸和视频时长；只使用受控文件句柄，未开放任意路径/URL。视频读取有字节预算和读取期限；单帧 WebM 缺少包时长时读取其容器时长。新上传必须探测成功才能 AVAILABLE。旧 AVAILABLE 文件保留原内容和空尺寸/时长，UI 如实标明未记录，不伪造数据或修改不可变文件。

本地原件使用分块 SHA-256，避免把大母版整体读入内存；只登记文件名、归档号、摘要和大小，不传本机路径或原文件字节。图片/视频上传上限继续为 10 / 100 MiB。本地驱动尚未代表云端对象存储已经部署。

## API 补充

- `GET /api/admin/content-revisions` 增加 `current=true`、`creativeProfileRevisionId`、`platform`、`status`、`style`。查询当前稿必须指定 productId。先取各素材/题库版本的最新修订，再执行筛选；历史草稿不会因匹配筛选而冒充当前稿。
- 内容详情增加 `previewFile / deliveryFile` 的严格文件 DTO。文件 DTO 增加可空尺寸和时长。引用/制作记录的 scope 统一为契约的小写值。
- 前端分页读取完整版本/设定及当前稿，不以第一页替代所有版本。继续复用原管理 API、CSRF 客户端与身份切换保护。
