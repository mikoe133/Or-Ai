# 商品详情页布局说明

日期：2026-10-13。参考：当前采用的商城首页，品牌 meetmyworld。

以“伴侣协作体检”的未领取状态为例。推荐采用方案 01 左右双栏。

画布：Web 端宽 1440 px，页面高度随内容延伸，示例约 1600 px。沿用首页的 72 px 顶部导航、约 224 px 左侧“我的空间”和右侧内容区。主要间距 24–32 px，卡片圆角 20–28 px；主标题 36–42 px、正文 14–16 px。上述数值为作图建议。

1. 顶部保持品牌、搜索、“我的空间”、登录/注册；侧栏“应用商城”保持选中，保留“我的应用”“我的报告”“使用帮助”和兑换入口。
2. 内容区顶部放返回商城和“应用商城 / 关系情感 / 伴侣协作体检”面包屑。
3. 首屏商品概览采用左右双栏：左边约 42% 为浅紫封面，延续首页的透明紫色玻璃丝带与悬浮球；右边约 58% 为深色信息卡。依次放分类、标题、钩子、简介、16 道题/约 3 分钟/5 个维度、参考价 ¥9.9、输入兑换码主按钮、查看购买说明次按钮。标注演示商品、暂无正式购买；按钮旁说明无需登录。
4. 商品概览下方放测评介绍和“你将了解什么”，用五个简短模块呈现家务主动性、承诺兑现、共同决策、沟通修复、边界尊重。
5. 放公开报告样例：结果类型、雷达图或横向维度条、简短解释。必须写“示意”和“样例数据，不代表真实测评结果”；不放完整题库或真实私人报告。
6. 放购买/兑换四步：平台购买 → 获取兑换码 → 输入兑换码 → 完成测评。说明使用期限以兑换权益为准，正式价格与期限后续确定。
7. 底部放三个相关测评推荐，沿用首页商品卡；最后放趣味自测说明与帮助入口。

视觉：近黑 #101117，石墨灰卡片 #1B1D27，粉紫主色 #D5A7EE，白色标题、浅灰正文，细银灰描边、磨砂玻璃感、克制的边缘光晕。封面使用浅紫/冰蓝/薄荷绿/淡粉的抽象 3D 玻璃造型。主阅读区域保持高对比和完整留白。

交互状态另画：未领取显示“输入兑换码”；已领取未开始显示“开始测评”；进行中显示“继续测评”；已完成显示“查看报告”。无封面、下架、长标题、加载失败为组件或页面状态，不全部堆在同一主图里。

正式作图时，报告维度分数按项目的 0–100 规则展示；生成图中的小数分数仅作图表形态参考，题量、耗时、价格也均为设计示例。图中细字以本文文案与实际产品配置为准。

四张方案：01 左右双栏；02 横幅主视觉；03 模块卡片；04 右侧固定兑换栏。它们是同一商品的四个布局备选，非四个顺序步骤。使用内置 image_gen 工具生成，未修改 Figma 原稿。
