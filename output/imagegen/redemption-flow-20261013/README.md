# 兑换界面与兑换成功界面 · 8 张 AI 方案

使用内置 image_gen 生成，沿用当前商城的深色玻璃表面、淡紫色按钮、紫色丝带与悬浮球插图。成功图逐张使用对应兑换图作参考，以维持前后状态一致。

推荐采用 **02 横幅主视觉**，与已选定的商品详情页衔接最自然。01 更聚焦输入任务；03 更突出操作步骤；04 可从详情页直接展开。

流程：商品详情的「输入兑换码」 → 兑换页输入或粘贴 →「确认兑换」→ 兑换成功 →「开始测评」。

兑换页核心 UI：返回商品详情、商品摘要、题量与耗时、兑换码输入框、粘贴、确认兑换、兑换码获取说明、客服入口、访客提示。

成功页核心 UI：成功图标、兑换成功标题、已解锁状态、商品摘要、开始测评、返回商城、登录同步提示。成功状态表示领取测评完成。
