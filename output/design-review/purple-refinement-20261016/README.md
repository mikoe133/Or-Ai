## 与现有设计的关系

直接读取并参考现有 [首页截图](../../implementation/homepage/perspective-mesh/desktop.jpg)、[商品页截图](../../implementation/store-flow/desktop-product.png)、[报告页截图](../../implementation/store-flow/desktop-report.png)。色彩延续 apps/web/src/store/home.css 中的背景 #101118、文字 #f6f4fa、次级文字 #a4a2b2、品牌 #d9acf1、抬升表面 #242630；生成图仅为视觉目标，颜色并非逐像素测量值。

- 顶栏继续承担搜索和账户入口，左侧保留常用导航，选中状态使用紫色。
- 首页收敛外框发光、网格和重复工具栏。封面分别表达相处、工作、想象与社交；卡片文字区域统一，方便比较。
- 商品页继续用深色与浅紫按钮，加入真实题目节选和报告片段；保留演示商品状态和兑换入口。
- 报告采用连续阅读布局，先给观察与依据，再给表达建议，五个维度作为补充。保留单人作答视角，数据明确为示例。

## 动效样例与实施提议

审阅页用真实 HTML/CSS 实现选择、下一步和重置；不保存答案、不调用业务 API。

- 选中：160 ms 边框/底色变化，始终同时显示明确的选择标记。
- 切换：220 ms 淡入，最多 8 px 位移。
- 支持 Tab、单选方向键与可见焦点；系统减少动态效果时禁用过渡。
- 上述时长是本项目提议，并非从参考网站测得的参数。

正式页面可让封面只在悬停时轻微放大，将反馈集中在用户操作附近；报告正文保持安静，避免持续漂浮、闪烁与自动滚动。
