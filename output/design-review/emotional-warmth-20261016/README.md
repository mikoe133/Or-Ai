# 情绪价值方向的页面改进提案

日期：2026-10-16。产物：三张 AI 生成的桌面 UI 设计概念图。生成方式：内置 image_gen，结合现有页面截图与新报告图作为参考，未使用 CLI。

这些图片用于比较视觉与内容层级，尚未修改网页源码或 Figma。图片中的文案、商品与分数均为设计示例；保留原截图及生成原文件。

## 调整优先级

| 优先级 | 页面与原截图 | 观察到的问题 | 建议 |
| --- | --- | --- | --- |
| P1 | [报告页](../../implementation/store-flow/desktop-report.png)、[手机报告](../../implementation/store-flow/mobile-report.png) | 总分首屏和连续维度/进度条占比高，阅读更像数据看板 | 首屏先呈现理解与观察，再给交流问题/行动，维度放后；用安静、可读的内容面板和商品生活场景 |
| P1 | [商品详情](../../implementation/store-flow/desktop-product.png) | 抽象玻璃形体缺少生活情境，“队友/第二份工作”的对立表达与理解关系的目标有距离 | 以相处场景、可带走的收获、报告片段讲清体验；价格/兑换/购买说明保持清楚 |
| P2 | [答题](../../implementation/store-flow/desktop-answer.png)、[反馈展开](../../implementation/store-flow/desktop-feedback.png) | 双重侧栏/工具装饰分散注意，反馈长统计面板挤压题目 | 后续简化外围工具；保留明确选择/确认/保存提示，数据反馈作为可展开的次要层，不即时评价答案好坏 |
| P3 | [商城首页](../../implementation/homepage/perspective-mesh/desktop.jpg) | 抽象材质封面难区分具体场景，轮廓与网格占用视觉注意 | 保留搜索/分类/导航和四列商品逻辑，场景化封面与邀请式文案形成具体商品差异，减轻装饰 |
| 保留结构 | [兑换页](../../implementation/store-flow/desktop-redeem.png) | 表单与流程清楚，优先改视觉和产品小图即可 | 后续沿用新的字体/色彩/场景素材，继续保持兑换和状态文案准确 |

## 三张设计图

- [商城首页](01-home-warmth.png)：深色平台框架与柔和场景商品封面。
- [商品详情](02-product-warmth.png)：窗边两把椅子的关系主题，收获/流程/报告样例/兑换说明的阅读顺序。
- [完整报告](03-report-warmth.png)：暖象牙色阅读面板，理解/需要/交流入口在前，原五维参考值放在后。

共同保留现有波形圆形标识、深色导航、淡紫主按钮；建议导航名称为“发现体验、我的体验、我的报告、我的收藏、使用帮助”。新方案采用中文衬线标题、简洁正文、暖白/鼠尾草绿和生活场景，报告与详情共享同一商品意象。

本轮只选择一种“安静、温暖的数字空间”方向；手绘、像素、3D 等其他商品风格仍可按各商品创作设定探索。这不是已采用的全站改版决定。
