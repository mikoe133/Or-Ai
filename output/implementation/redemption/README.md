## 范围

本轮完成两页的可交互设计预览，未接入真实兑换、权益、计分与报告接口。输入非示例码不会发送给后端，也不写入 URL、日志或浏览器存储。成功页可独立打开用于审稿；「开始测评」提供一道明确标注、不计分的公开示例，不代表完整测评已交付。真实商品详情、答题与报告页面不在本轮范围内。

粘贴按钮读取剪贴板；权限被拒或浏览器不支持时，聚焦输入框并说明键盘粘贴方式。帮助、客服说明、商城搜索、侧栏收起、登录与返回入口均有对应行为。返回商品详情会打开现有的伴侣商品预览弹窗。

## 设计与素材

设计依据为 Figma 文件 `TluUhd92v2Z2HztvQeGqxe`，兑换节点 `290:83`、成功节点 `300:777`。Figma MCP 设计上下文与截图调用仍返回 Starter 额度耗尽；没有取得新的 MCP 设计上下文。本轮对照此前保存的原始 SVG、图层尺寸记录与原生 PNG 导出实现，不宣称逐像素一致。

公共结构复用商城图标、Noto Sans SC / Manrope 字体、按钮样式与 `GlassFrame`。`GlassFrame` 增加 `guided` 变体，用原始轮廓的固定边角和可伸缩直线段匹配实际面板，默认商城变体保留。页面正文使用 HTML、CSS 与 React 控件，没有用整页截图作为 UI。

三份 SVG 从 `output/figma/` 原样复制到 `apps/web/public/assets/redemption/`。通过外部 SVG fragment 引用已有的插图、图标与轮廓分组，保留源文件根尺寸、路径与渐变；没有改写路径。商品封面复用商城中的同一份原图，并核对嵌入设计源的 PNG 摘要一致。素材哈希、分组、调用点见 `assets-verification.json`。

## 布局

1440 × 1024 基准：公共面板 `(72, 72)`、1296 × 907.4；内容两列为 640 / 347px，中间 24px；兑换卡 622px 高，成功卡 538px 高，底部同步提示 60px 高。

1200px 起使用双列；768–1199px 保留桌面导航并将主卡和说明卡上下排列；手机采用单列、精简顶部与固定底部导航。320px 窄屏与 844 × 390 横屏均检查过。轮廓与背景按实际容器尺寸计算，侧栏收起时分隔线跟随真实边界。
