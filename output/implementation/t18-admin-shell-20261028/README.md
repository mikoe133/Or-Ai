# T18 后台共享骨架与概览：首批改造

日期：2026-10-28。父任务仍为 active/17（稳定标识 T18）；05/06 的前置与未完成项保持。本批使用既有 NestJS/Prisma/PostgreSQL、React/Vite，不改变商品规划、权限和历史版本，不进行云部署或内容生成。

## 基线与具体问题

在同一合成隔离 TEST 数据库、同一真实 API/生产前端下，采集七类后台入口 × 1440×1000、768×1024、390×844，共21张可靠基线。合成管理员与普通成员使用既有 Auth 协议替身，不代表真实 Supabase 登录/邮件验收。数据是 seed 的演示数据，不是经营成绩。浏览器仅使用 CUA；三种尺寸是桌面视口模拟，不是真机。

改造前实际截图见 `before-verified/`，就绪条件、标题、选中链接和尺寸见 `before-verified/baseline.json`。原始首次尝试的五张图保留在 `before/`；该尝试在连接页因折叠区加载节点超时，没有记为整批成功。

1. 侧栏七个入口未分组；“工作空间 01”没有业务含义，底部全大写品牌重复。导航和概览重复的英文标签干扰扫描。
2. 概览坐标、筛选、说明有9/10px小字；数据含义和操作应更容易阅读。
3. 管理员验证点与品牌选中态同为紫色，状态和导航含义混用；概览仍写“四类 skill”，与实际五库不一致。
4. 工作区是 section，没有 main 地标。真实 AdminShell SSR RED 已编译运行：预期1、实际0，见 `landmark-red.json`，检查点696d890。
5. 390px 商品页文档宽550px，出现整页横向滚动。表格内部绝对定位的屏幕阅读器文字缺少合适包含块，滚动区域未能约束其溢出；共享工作区需建立定位上下文。

## 设计和实现

沿用 B「精密工具紫」：中性深色表面、细边界、紫色用于导航/主要操作，验证状态使用独立成功色。保持原七个链接顺序，增加“运营管理 / 内容制作 / 连接与交付”三组；统一44px导航行与文字层级，调整侧栏/顶栏/内容边距。

工作区改为唯一、有当前页面名称的 main，保留内部滚动和 skip link；移动导航选页后焦点进入工作区，Escape/Tab行为保留。定位上下文约束隐藏表头文字，宽表格继续在自己的滚动容器中操作。概览移除重复英文眉题及无额外含义的范围边框，提升筛选/图例/坐标/说明可读性，保留实际 API 指标、累计/当前页统计口径及表格明细。未登录面板移除纯装饰字标。
