## 背景光效动效

2026-10-15，按用户在桌面预览上的三处标注添加动效，运动参数由本轮标注需求确定。

- 左下绿色光晕：22 秒循环，屏幕坐标的横向偏移限定在 -28～36px，纵向偏移 -12～16px。
- 右下彩色光晕：29 秒循环，横向偏移 -20～18px，纵向偏移 -26～28px。两处使用错开的周期和不同路径，缓慢游动，首尾连续。
- 左侧白光：10 秒循环，只做上下各 12px 的垂直往返，水平位置固定。
- 彩色光晕通过原样内联本地 SVG 并移动原有光斑组实现。固定根尺寸、画布和裁切边界，避免移动整个图像后在页面外沿露出断层；动画与原有页面缩放分开，窗口变大或变高时运动振幅保持相同的屏幕像素范围。
- 只给三处装饰添加 transform 动画，玻璃轮廓、网格、侧栏、卡片和文字保持原有布局。手机继续使用其原有背景稿。
- 现有氛围光按钮可暂停/恢复并调暗光效；系统的 `prefers-reduced-motion: reduce` 会停止三处动画并移除动态层的 will-change 提示。

实际浏览器固定视口连续观察约 32 秒，采集 65 帧：三处均未超出限定范围，边框和内容几何保持一致，无页面横向溢出。暂停、恢复和减少动态效果设置通过；等待尺寸同步后复核 384/768/1024/1280/1440/1920 六种宽度，内容与内框包含关系及画布尺寸通过。构建通过，三份原始光效素材字节保持一致。
