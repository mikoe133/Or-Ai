1. [候选403 RED](red-candidate-403.json)：权限拒绝后仍显示原清理预演，原确认仍勾选，执行按钮仍可用。现在候选、恢复预演及操作权限失败均隐藏私有工作区，撤销原确认；必要读取全部成功才恢复，失败重读不能提前展示。
2. [候选503 RED](red-candidate-503.json)：普通失败替换掉已有表格。现在保留候选、选择和固定预演，显示缓存更新失败提示，核对成功前暂禁新操作；首次读取失败只显示实际错误，不伪造空态或保留了数据的提示。
3. 确认绑定具体预演ID和摘要；409保留选择，清除旧确认，成功重读后才能继续。已完成预演只读，固定标识/摘要收进可展开依据，文件名/大小留在主层。
4. 未知预演/清理保留原请求和固定选择/预演，锁住新操作；权限恢复后只能主动核对同一请求。父工作台同步保护页签、版本与离开，并明确显示“清理结果待核对”。未以丢弃草稿或刷新绕过未知结果保护。
5. 明确标题、更新入口、候选数与已选数，提升主要说明及控件字号，保持中性紫色表面。手机候选表使用栏内横向滚动，避免文件名被压成多行；未改商城或共享消费者组件。
