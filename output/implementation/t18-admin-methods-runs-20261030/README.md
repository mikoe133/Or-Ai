2. 普通503不再卸载方法定制、回执搜索、历史页签或固定尝试选择器。409保留完整定制输入，重新读取基础版本后仍须明确复核。未知方法保存保留原请求；权限恢复后核对同一请求，不另建请求。
3. 停止结果未知时保留原原因、预览和请求。权限恢复不自动重开停止对话框，通过“核对原停止请求”主动打开；原因锁定、新停止和批次切换继续受限，重试摘要与原请求一致。费用未知仍明确显示未知，停止平台接续不冒称终止外部作业。
4. 增加手机模块选择器和未保存切换确认；取消恢复选择器焦点，放弃定制导致原触发按钮消失时回到可见选择器或交接入口。
5. 收敛英文装饰眉题，沿用后台中性表面与紫色识别；辅助文字提高至12–13px，调整模块目录对齐、弹窗表面及窄屏表单。完整Three.js政策正文保留，未改商城或影响商城的共享样式。
