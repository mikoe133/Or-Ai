# Task 07 · 离线云适配实施合同

2026-10-28（Asia/Shanghai）。沿用已确定的香港VPS＋Cloudflare＋Supabase＋R2＋Resend方案。07只实现和隔离验证应用/部署适配；08持有真实部署、DNS、认证/邮件、真实对象读写及恢复。本批不加载`.env.memo`、访问实际云资源或创建持续凭据。

## 固定边界

- 现有业务管理员/机器范围、数据库权限、固定版本/摘要、原件非执行与私有下载规则继续生效。R2适配不能新增审核/发布/退款权限，也不生成公开桶链接。
- 商品图片、视频、Skill附件及HTML/ZIP/GLB原件复用原类型、大小、摘要、容器结构和几何检查。数据库中只保存原有对象key与精确元数据，不改变历史清单。
- 对象上传必须在验证后以条件写入创建，不能覆盖同key历史。读取固定HEAD/ETag并校验完整长度与SHA-256；损坏、变更、超限和提供者失败均拒绝，并清理本进程创建的临时文件。
- 当前检查器依赖随机读。R2读写使用有总字节/文件数配额的私有临时目录，只承担检查和授权流式响应；关闭、流结束、客户端中断与失败均释放。服务器部署再对临时盘设置系统级容量和单实例上限，不能把进程内配额说成多实例全局配额。
- 配置仅接受固定R2账户端点、私有桶和独立服务器凭据；不接受任意用户URL，不反射凭据或厂商错误。运行时关闭文件存储仍按既有明确失败方式处理。
- 模拟S3协议、真实SDK和隔离服务验证的是应用兼容性，不能认定实际R2、云权限、撤权、容量或恢复已验收。

## 实施顺序

1. R2存储合同、RED checkpoint → 共享检查器与受控临时句柄 → R2条件写入/固定读取 → 配置/服务接线 → SDK本地协议与既有业务回归。
2. VPS同域路由/容器与恢复配置，统一入口/应用/SDK字节和超时预算，隔离测试。
3. 独立云初始化执行器与受限角色/迁移/PRODUCTION marker，保留本地维护拒绝远程规则；只验证本地隔离目标，不执行真实云初始化。
4. 汇总运行限制、费用/错误观测、备份对象清单和回滚说明，再交08执行真实验收。

本合同是实施要求，不是已完成记录。Task05的具体商品规划尚未固定，不阻塞上述独立存储/部署代码；不因其等待就重启真实内容或模型作业。
