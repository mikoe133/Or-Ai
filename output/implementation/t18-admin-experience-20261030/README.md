## 实际问题与改动

- 既存 [读取失败 RED](red-failed-reload.json) 会用缓存替换本地输入，仍提示已读取最新稿。现在工作区、历史及失败的嵌套读取全部成功后才报告完成；普通核对保留草稿和历史选择，明确采用最新稿才替换输入。
- 既存 [未知保存 RED](red-unknown-save.json) 允许继续编辑。保存和审核现在保留完整原请求；未知结果锁定编辑、采用、版本/设定及离开操作，只允许显式核对同一请求。403 不能把先前未知请求当作未执行，409 则保留草稿并要求重读。
- 既存 [历史权限 RED](red-history-403.json) 仍显示私有编辑器。工作区、历史、方法候选、固定规划或操作拒绝时隐藏编辑器；保留状态，但只有必要读取全部成功才恢复。
- 历史选择保留精确修订快照，不回落成当前稿。历史修订仍可做原有只读兼容检查/演示操作，保存和审核保持禁用。

设计沿用 B「精密工具紫」和已有后台令牌。删除重复的英文装饰眉题，将“核对服务器状态”和“采用最新稿”分为明确操作；未知请求在有语义的状态区中恢复。没有增加装饰图表、全页光效或业务新流程。
